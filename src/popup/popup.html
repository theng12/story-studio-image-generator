Leonardo options
Reference —
Story Studio auto-ingest is unavailable for Leonardo. Attach references in your Leonardo tab (under the prompt → “Add reference to generation”); they apply until removed. Models without reference support ignore them.
Google Flow options
Web providers choose models in their signed tabs. Flow discovery is live when exact provider-owned IDs are available and otherwise uses the three tested fallback records. Changed or unknown verifiable selections require refresh and re-queue.
Google AI Studio options
Open aistudio.google.com in image mode (pick an image model, e.g. Nano Banana 2 Lite) and keep that tab visible. The extension sends “Create a <ratio> image of …”, runs it, and reads the result; ratio is best-effort via the prompt. Uses your free daily image quota; when it's exhausted the queue pauses until you press Resume after the reset.
Story Studio references are pasted into AI Studio before each image (up to 4), then checked before generation.
ChatGPT options
Uses your signed-in chatgpt.com tab — keep it the visible/active tab (a hidden/minimized tab gets its timers throttled and generation crawls). Ratio is set via the prompt ("Create a <ratio> image of …"). Each scene opens a fresh chat (a full page load) — ChatGPT stalls if a 2nd image is requested in the same page session, and a fresh load is what clears it. The wait is progress-aware: it keeps waiting while ChatGPT is actively generating and only gives up if it goes quiet with no image; Max wait is the hard ceiling for a slow-but-working image. Story Studio can paste up to 4 references into the composer before each image. Image quota is limited; when it's hit the queue pauses so you can rotate providers.
Qwen Studio options
Uses your signed-in chat.qwen.ai session and asks Qwen to create one image per scene. The extension reinforces this ratio with both exact dimensions and natural-language canvas instructions, but it remains best-effort because Qwen may choose its default shape. Human Pace applies between every request. Qwen limits ~30 images per window; how a quota hit is handled (pause vs. auto-resume) is set in the Provider cooldown card above.
Story Studio can attach one reference before each image. Qwen consumes it per generation, so it re-attaches every time.
