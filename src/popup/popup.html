Pollinations options
Runs in the background — no tab needed. Free/anonymous is rate-limited (~1 image/15s) and watermarked; register at auth.pollinations.ai and paste a token to remove the watermark and go faster. Aspect ratio follows your scene setting.
Grok Imagine options
Set model, aspect ratio, style and Image/Video on the Grok Imagine page — Grok saves them to your account and the extension replays your prompt with whatever you last chose there. Set them once; they apply to every scene. (Grok takes no per-request options, so there's nothing to set here.)
Google AI Studio options
Open aistudio.google.com in image mode (pick an image model, e.g. Nano Banana 2 Lite) and keep that tab visible. The extension sends “Create a <ratio> image of …”, runs it, and reads the result; ratio is best-effort via the prompt. Uses your free daily image quota; when it's exhausted the queue pauses until you press Resume after the reset.
Character reference (img2img) is supported: pick a character below and its sheet is pasted into AI Studio before each character scene.
ChatGPT options
Uses your signed-in chatgpt.com tab — keep it the visible/active tab (a hidden/minimized tab gets its timers throttled and generation crawls). Ratio is set via the prompt ("Create a <ratio> image of …"). Each scene opens a fresh chat (a full page load) — ChatGPT stalls if a 2nd image is requested in the same page session, and a fresh load is what clears it. The wait is progress-aware: it keeps waiting while ChatGPT is actively generating and only gives up if it goes quiet with no image; Max wait is the hard ceiling for a slow-but-working image. Character reference (img2img) is supported — pick a character below and its sheet is pasted into the composer before each character scene. Image quota is limited; when it's hit the queue pauses so you can rotate providers.
PicLumen options
Uses your signed-in piclumen.com session (model PicLumen Art V1) through its API. Free tier is ~10 Lumens/day (1 per image); aspect ratio follows the scene setting. When the free quota runs out the queue pauses so you can rotate providers — enable auto-resume in the Provider cooldown card to retry after the daily reset instead. Character-reference img2img is coming later.
Qwen Studio options
Uses your signed-in chat.qwen.ai session and asks Qwen to create one image per scene. The extension reinforces this ratio with both exact dimensions and natural-language canvas instructions, but it remains best-effort because Qwen may choose its default shape. Human Pace applies between every request. Qwen limits ~30 images per window; how a quota hit is handled (pause vs. auto-resume) is set in the Provider cooldown card above.
Character reference (img2img) is supported: pick a character above and its sheet is dropped into the composer before each character scene. Qwen consumes it per generation, so it re-attaches every time.

Provider cooldown
—
Off = the queue pauses on a limit and waits for you to press Resume (default). On = it waits the chosen time, then resumes on its own — press Resume any time to override. Qwen uses its own stated wait when it gives one.
This provider has no automatic limit detection — it just stops on error.
