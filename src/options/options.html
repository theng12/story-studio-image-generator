Story Studio Image Generator — Settings

Appearance
Story Studio
Server URL
Local studio (localhost) needs no login or access grant. A remote/Tailscale server (e.g. http://mac-mini.tailXXXX.ts.net:8677) needs both.
Human-paced queue
A new delay is chosen between these values after every provider attempt. Use equal values for a fixed delay, or 0 and 0 to disable it.
Flow reCAPTCHA recovery
Fresh-token attempts per generation
Flow mints this many fresh reCAPTCHA tokens within a single image generation (1–10, default 4) before giving up on that image. What happens after it gives up — pause vs. auto-resume, and after how long — is set per provider in the side panel's Provider cooldown card.
Perchance
Art style
Applied explicitly to every Perchance job. “No style” lets the Story Studio prompt control the look.
Leonardo AI
Image model
“Unlimited” is Leonardo's catalog badge, not a zero-token guarantee. Check the Generate button's displayed cost for your current plan. Refresh reads the live model list from a logged-in Leonardo tab, so new models appear here automatically.
Visual style
Style availability can vary by model. The queue stops with an actionable error if Leonardo removes the selected combination.

Flow project ID
